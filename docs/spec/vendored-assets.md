**SHA-256 policy.** `scripts/vendor.sh` hard-codes the full URL and SHA-256 of every download (the
values above), verifies each before extracting, and aborts with `error: SHA-256 mismatch for <url>`
(expected and actual printed) leaving `assets/vendor/` untouched. Pins were cross-checked against
npm `dist.integrity` (sha512) and the crates.io index `checksum` (= SHA-256 of the `.crate`); all
matched. packages.typst.org and raw.githubusercontent.com publish no checksum: trust-on-first-use,
recorded here and in VERSIONS.toml. Never pin a moving URL (a branch name, `latest`, an npm range).

### 2.1 Rules for the consumers
- `katex.min.css` references `fonts/KaTeX_*.woff2` first and `.woff`/`.ttf` fallbacks, which stay in

  `UrlRules::for_style(..).is_lenient()`, lifted) leaves an unresolvable `url()` in a stylesheet
  under `vendor/` unchanged, without error; in theme-chain stylesheets it is `Error::Style`.
- A standalone HTML file inlines by `Emitted.math` (`MathUsage`, html-output.md §4.3): KaTeX (js +
  css + fonts) only when `katex` (a LaTeX equation took the `katex` route); `latinmodern-math.woff2`
  when (`mathml` or `typst_mathml`) and `[math] mathml_font = "embed"`, which includes typst-dialect
  equations under the default `html = "katex"` (the CSS rule is math.md §4.3's).
- morphdom is served by `writer serve` only (live-reload.md), never in a build output. The UMD file
  defines `window.morphdom` (`global.morphdom=factory()`).
- mitex is served to the compiler only (§5.3) and written out by `eject typst-package`; emitted `.typ`

### 3.7 The Unicode→LaTeX table (`scripts/gen-unicode-latex.py`, T51)
`assets/math/unicode-latex.toml` is derived from tylax 0.3.8 (Apache-2.0; tylax states its maps
are derived from tex2typst, also Apache-2.0) by a stdlib-only Python ≥ 3.11 script, run by hand
and committed. math.md owns how the converter uses the table; this section owns its content.

Inputs, downloaded with pinned URL + SHA-256 (§1 policy) into a temporary directory; only these
members are read, with `tarfile` (never `extractall`; names include the `<name>-<version>/` top dir):

| crate | URL | SHA-256 | members read |
|---|---|---|---|
| tylax 0.3.8 | `https://static.crates.io/crates/tylax/tylax-0.3.8.crate` | `145d65de…0672` (§1) | `tylax-0.3.8/src/data/maps.rs`, `tylax-0.3.8/src/core/typst2latex/utils.rs` |
| codex 0.3.0 | `https://static.crates.io/crates/codex/codex-0.3.0.crate` | `0732ab1a27b4ea05e6f9f60a5122c9924dd5123defde0d8e907f58cf643d40e6` | `codex-0.3.0/src/modules/sym.txt` |
| typst-syntax 0.15.1 | `https://static.crates.io/crates/typst-syntax/typst-syntax-0.15.1.crate` | `92a20d79df5d10c7fb0b4f7c18e4b2671edfc21e5ed9ad9894e18cccefd1c70f` | `typst-syntax-0.15.1/src/ast.rs` |

Procedure (deterministic; any parse count different from the expected one aborts with exit 1):
1. **N** (name table): in `maps.rs`, from the line containing `pub static TYPST_TO_TEX` to the
   next line equal to `};`, every line matching `^\s*"((?:[^"\\]|\\.)*)"\s*=>\s*"((?:[^"\\]|\\.)*)",\s*$`
   (Rust escapes `\\` `\"` decoded), in source order. Expect 532.
2. **U** (char table): in `utils.rs`, from `pub static ref UNICODE_TO_LATEX` to the next line
   matching `^\s*};`, every `m.insert('C', "V");`, in source order. Expect 159.
3. **S** (shorthands): `LIST` after `struct MathShorthand` in `ast.rs`, each `("K", 'C')`. Expect 38.
4. **codex**: parse `sym.txt` as codex's `build.rs` does: strip `//` comments and blank lines;
   `@deprecated: …` applies to the next declaration (deprecated names still resolve); `name {`
   / `}` open/close a module (names inside get the `module.` prefix); `name [value]` declares a
   symbol; `.m1.m2 value` declares a variant of the current symbol with modifier set {m1, m2};
   values decode `\u{XXXX}` and `\vs{1..16|text|emoji}` (U+FE00…U+FE0F). Expect 1,206 names (each
   symbol line that carries a value, 288, plus each variant line, 918, written `symbol.m1.m2`)
   under 334 symbols (46 of them, such as `paren`, have variants only).
5. **normalise(v)**: starts with `\` → `v`; matches `^[A-Za-z]{2}` → `"\" + v`; else (a letter,
   punctuation) `v` unchanged.
6. **names table** = `{key: normalise(v)}` for N, then the `[names]` overrides (step 9).
7. **resolve(key)**: if `key` is in S → that char; else split on `.`, take the longest prefix that
   is a symbol, the rest is the requested modifier set R; among the symbol's variants whose set ⊇ R
   (the plain value counts as the empty set) pick the one with the fewest modifiers, the first listed
   on ties (codex's `best_match_in`); strip trailing U+FE0E/U+FE0F; not one scalar → *unresolved*.
8. **chars table**: for each names-table entry (N order, then names added by overrides in key
   order) whose key resolves to `c`, set `chars[c]` unless already set (first wins); then each U
   entry, in source order and with its value as written, overwrites `chars[c]`; then the
   `[chars]` overrides. A *conflict* is a set or overwrite that meets a different LaTeX string.
   Then **alnum**, for each assigned code point `c` in U+1D400–U+1D7FF still unset and not deleted by
   an override, in order: `style` = the words of `unicodedata.name(c)` after `MATHEMATICAL ` among
   BOLD ITALIC SCRIPT FRAKTUR DOUBLE-STRUCK SANS-SERIF MONOSPACE; `b` = NFKC of `c`; `x` = `b` if ASCII
   alphanumeric, else `chars[b]` (unset: skip). BOLD → `\mathbf{x}` (non-ASCII `b`: `\boldsymbol{x}`),
   ITALIC `\mathit`, BOLD ITALIC `\boldsymbol`, SCRIPT `\mathcal`, FRAKTUR `\mathfrak`, DOUBLE-STRUCK
   `\mathbb`, SANS-SERIF (ITALIC) `\mathsf`, MONOSPACE `\mathtt`, BOLD SCRIPT / BOLD FRAKTUR /
   SANS-SERIF BOLD (ITALIC) → `\boldsymbol{\mathcal{x}}` / `…{\mathfrak{x}}` / `…{\mathsf{x}}`;
   SCRIPT, BOLD SCRIPT and DOUBLE-STRUCK only for ASCII capitals (amssymb has no others).
9. Overrides: `scripts/unicode-latex-overrides.toml` (hand-written, T51): `[names]` and `[chars]`
   (strings; a value replaces, `""` deletes) and `[packages]` (`"\\coloneqq" = "mathtools"`: command →
   the package defining it beyond amsmath+amssymb); after step 8 every entry whose `tex` contains such
   a command (not followed by a letter) gets that `package` (two packages in one value abort).
   Required initial content (pdflatex-verified): `[names]` `paragraph = "\\P"`, `section = "\\S"`,
   `thin = "\\,"`, `med = "\\:"`, `thick = "\\;"`, `AA = "\\mathbb{A}"`, `EE = "\\mathbb{E}"` (tylax:
   `forall`, `exists`); `[chars]` `"U+2605" = "\\bigstar"`, `"U+27E6" = "\\llbracket"`, `"U+27E7" =
   "\\rrbracket"`, `"U+03BF" = "o"`; `[packages]` mathtools: `\coloneqq` `\Coloneqq` `\eqqcolon`;
   stmaryrd: `\llbracket` `\rrbracket` `\mapsfrom` `\Mapsto` `\bigsqcap`; esint: `\oiint`; mathdots:
   `\iddots`; gensymb: `\degree`; eurosym: `\euro`. Overrides act only here: the committed file is
   final (math.md §3.3's "hand overrides consulted first" are these).
10. Report on stderr: the counts, every conflict and every unresolved key. With an **empty**
    overrides file the expected report is: names 532, chars 1,292 (405 from N and U, 887 alnum),
    conflicts 17, unresolved 87 (54 undotted keys such as `Pr`, `arccos`; 33 dotted keys codex
    0.3.0 no longer has, such as `angle.l`, `circle.plus`). `--check` regenerates in memory and
    exits 1 if the committed file differs (CI, §5.5).

Output, UTF-8, LF, no trailing spaces, sorted (`[names]` by key in code-point order, `[chars]`
by code point), TOML basic strings with `\\`, `\"` and `\uXXXX` for U+0000–U+001F/U+007F:

```toml

# Derived from tylax 0.3.8 (Apache-2.0, https://github.com/scipenai/tylax): TYPST_TO_TEX in
# src/data/maps.rs and UNICODE_TO_LATEX in src/core/typst2latex/utils.rs, modified by writer
# (normalised, resolved through codex 0.3.0, merged, overridden). License: vendor/crates/tylax/LICENSE.

[source]
tylax = "0.3.8"
codex = "0.3.0"
typst-syntax = "0.15.1"

[names]
"!=" = { tex = "\\neq" }
":=" = { tex = "\\coloneqq", package = "mathtools" }

[chars]
"U+2192" = { char = "→", tex = "\\rightarrow", from = "chars" }
"U+1D400" = { char = "𝐀", tex = "\\mathbf{A}", from = "alnum" }
```

Keys in the order `char`, `tex`, `package` (only when set), `from`; `from` is `"names:<key>"`,
`"chars"`, `"override"` or `"alnum"`. The loader fills math.md §3.3's `Sym { tex, package }` and
ignores `char`/`from`. Acceptance (T51 test): the key's code point equals `char`; with the required
overrides U+00A7 → `\S`, U+00B6 → `\P`, U+03B1 → `\alpha`, U+03B5 → `\varepsilon`, U+2192 →
`\rightarrow`, U+2605 → `\bigstar`, U+211D → `\mathbb{R}`, U+1D400 → `\mathbf{A}`, U+1D538 and
`AA` → `\mathbb{A}`, U+2254 and `:=` → `\coloneqq` + `mathtools`; with `pdflatex` installed (else
`skipping`) every distinct `tex`, as `$x <tex> y$` under `amsmath`, `amssymb` and its `package`,
compiles (33 values fail with an empty overrides file, 23 with the required ones, e.g. `\eq`, `\lt`,
`\argmax`, `\napprox`: T51 overrides them). tylax is not a Cargo dependency, normal or dev (it pins
typst-syntax 0.14).

### 8.3 Release archive layout (T75, lifting presenter's "third-party licenses" step)
```
writer-v<version>-<target>/THIRD-PARTY-LICENSES/
├── EMBEDDED.txt     output of the archived binary's `writer --licenses`
├── assets/<path>    a copy of every §8.1 file at its assets/ path
├── crates.txt       "<name> <version>: <license> (<crates.io URL or path>)" per linked crate, sorted
└── crates/<name>-<version>/   LICENSE*, COPYING*, NOTICE*, UNLICENSE* of each linked crate
```
"Linked" = `cargo tree -e normal,no-proc-macro --target <target>`. Join that target's
uncolored package identities to metadata exactly. Registry notices are searched
recursively; workspace/path crates use root notices plus explicit license_file,
without sweeping build/test/embedded-asset trees. Copy actual notices byte-exact.

If no notices exist, generated `LICENSE-MIT` is permitted only when the parsed
Cargo expression can be satisfied by plain MIT alone. OR and Cargo's legacy
`/` allow a choice; AND preserves all obligations. Thus `Apache-2.0/MIT`
qualifies but `MIT AND Apache-2.0` does not. SPDX grouping/precedence and
case-sensitive operators apply; canonical MIT identity is case-insensitive.
WITH-qualified terms, MIT-0, LicenseRef/DocumentRef, substrings, exception tokens,
ANSI and malformed syntax cannot stand in for plain MIT. This is syntax/choice
evaluation, not a complete SPDX identifier/exception registry validator. Preserve
the declared expression in crates.txt and invent no copyright owner or non-MIT
license. Sources: [Cargo legacy convention](https://doc.rust-lang.org/stable/style-guide/cargo.html#metadata-conventions),
[Cargo operators](https://doc.rust-lang.org/cargo/reference/manifest.html#the-license-and-license-file-fields)
and [SPDX syntax/case/precedence](https://spdx.github.io/spdx-spec/v2.3.1/SPDX-license-expressions/).

**Reviewed immutable source-copy exceptions:** only the exact 21 package/version
records in [release notice sources](../dev/release-notice-sources.json) may copy
the following additional reviewed notices when published source notices are absent:

- mitex, mitex-glob, mitex-lexer, mitex-parser, mitex-spec and mitex-spec-gen 0.2.4:
  existing embedded mitex package LICENSE, verified identical to their pinned
  workspace root LICENSE; no upstream NOTICE exists.
- roman-numerals-rs 3.1.0: exact upstream `LICENCE.rst`, retaining both declared
  0BSD/CC0 alternatives and attribution.
- typst, typst-eval, typst-html, typst-kit, typst-layout, typst-library, typst-pdf,
  typst-realize, typst-render, typst-svg, typst-syntax, typst-timing and typst-utils
  0.15.1: existing embedded typst-assets LICENSE (verified identical) plus exact
  upstream Typst NOTICE. The typst-assets NOTICE is a different file and is not
  a replacement for this NOTICE.
- selectors 0.41.0: exact official versioned MPL 2.0 full text, its verbatim
  published source header and source provenance. No upstream root LICENSE is
  invented. Its normal crates.txt URL field must contain the pinned complete
  source archive URL `https://static.crates.io/crates/selectors/selectors-0.41.0.crate`;
  a landing-page-only attribution is insufficient.

One shared guard requires exact package source/repository/license declarations
and absent license_file, unique Cargo.lock identity and reviewed checksum,
actual cached archive SHA-256, one regular archive VCS record identical to
extracted source bytes, and exact clean revision/package path. Each reused
notice must match its reviewed runtime SHA-256. Release-only copies live under
`docs/release/notice-sources/<project-version>/`, canonically confined beneath
the helper checkout; metadata's workspace root still owns lock/cache guards.
They remain outside embedded assets, with `-text -whitespace` preserving their
exact legal bytes. There is no runtime notice download or broad non-MIT
generation. Each linked crate retains its own declared expression/attribution;
unlinked pin records add no rows. Other missing notices or evidence fail.

The step also fails when a linked crate is absent or ambiguous in metadata,
when embedded copies/stdout differ, or when the binary exceeds the §6 ceiling.
`docs/dev/release.md` (T75) describes archive validation and evidence boundaries.
