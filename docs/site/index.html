A command-line tool, one binary

Write once.
Typeset everywhere.

Write a report in Markdown, a saved Jupyter notebook or Typst. writer builds a web page, a typeset PDF, an editable Word file, LaTeX or Typst source from it, and previews every edit while you write.

Live preview

writer serve rebuilds on every save and shows the web page or the typeset pages. A failing edit keeps the last good result on screen and points at the line.

Notebooks, as saved

Plots, DataFrames and tracebacks come from the notebook's saved outputs. No kernel runs, so a build needs no Python.

References that travel

Numbered figures, tables and equations, cross-references, footnotes, citations and a bibliography, on the web, in the PDF and in Word.

Math everywhere

LaTeX math becomes KaTeX or MathML on the web, typeset math in the PDF and editable Word equations, with an image where Word's equations fall short.

Everything inside

The Typst compiler, fonts, KaTeX, the theme and the document package are embedded. Web, PDF and Word need no TeX, Typst CLI, Chrome or Node.js.

Yours to restyle

Themes are CSS and Jinja templates. Eject the built-in theme, Typst template, LaTeX template or Word reference document and change them.

Download

Each release has one archive per platform: macOS (Apple silicon and Intel), Linux (x86_64 and arm64, glibc) and Windows (x64 and arm64). The archive holds the writer binary, its license and the notices of everything it embeds.

${download}

Or build from source with Rust 1.96 or newer: cargo install --path . --locked in a checkout. The getting started guide has the details.

In 30 seconds

writer init report --bib              # a document, writer.toml, a theme and refs.bib
cd report
writer serve document.md --open       # live preview; press p for the typeset pages
writer build document.md              # Wrote dist/document.html (683.8 kB)
writer build document.md --to pdf,docx
