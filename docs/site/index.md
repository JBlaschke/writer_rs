# Documents from one source

Write a report in Markdown, a saved Jupyter notebook or Typst. Build HTML,
PDF, Word or portable source, and preview changes while you write.

[Read the guide](writer-site:guide) or start with
[installation and a first document](writer-site:guide-getting-started).

| Example output | Demonstrates |
|---|---|
| [Markdown report](writer-site:example-basic) | Figures, tables, code, equations and footnotes |
| [Saved notebook](writer-site:example-notebook) | A stored plot, DataFrame and traceback |
| [Native Typst](writer-site:example-typst) | A native source rendered through its structured web path |

Notebook builds read saved results; they do not run a kernel. Native Typst
compiles directly for PDF, while structured exports support a documented
subset. LaTeX export writes source and resources for a separate TeX
installation. See [output choices](writer-site:guide-outputs).

The examples here are static HTML built from the repository's actual sources.
Use the guide to build the other formats locally. This artifact does not
provide release downloads or claim a deployed project URL.

binary used for this build. Browse the [source revision](writer-site:repository)
